# Security policy

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use **Security > Advisories > Report a vulnerability** in the public GitHub repository after private vulnerability reporting has been enabled by its owner.

Include affected versions, reproduction steps, expected impact, and any proposed mitigation. Please allow maintainers reasonable time to investigate before public disclosure.

## Supported versions

Until a stable release line is declared, security fixes apply to the current default branch and the latest published release candidate only.

WidgetStudio does not include an updater. Users must replace an older portable folder with a newly published release after preserving any desired portable `data` directory.
